Validation was not a green-check exercise — it exposed four real defects, all now fixed:

| # | Defect | Root cause | Fix |
|---|--------|-----------|-----|
| 1 | Double disulfide-Cys mutant was auto-"repaired" and passed | Correction restored C23/C104, audit then scored them 'corrected' | Added rule: if both C23 and C104 are non-Cys before correction → FAIL (no Ig fold) |
| 2 | Random noise (non-antibody) was force-corrected and passed | Motif detection fell back to structural estimates on non-antibody input | Added confidence flags: if neither FR2 W-motif nor FR4 J-motif matched → FAIL (not antibody-like) |
| 3 | F118 correction direction was inverted | F118 assumed F for heavy chain; actually JH genes use W (WGQG), JK/JL use F (FGQG) | Corrected: VH→W |
| 4 | C104 mis-localized by 1 residue when mutated | Fixed `F118−6` offset inaccurate for VH (true distance 5) | Fixed offset: VH→5 |
| 5 | Length anomaly initially mis-classified | Status checks ran motif/AA checks before length check | Reordered: length check now precedes motif/AA checks; length anomaly → FAIL |
